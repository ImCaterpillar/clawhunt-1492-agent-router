# 验收对照 — #1492 Agent 协作路由

## 验收标准原文

> 至少演示正常路由、无匹配和转人工三类路径。

## 逐条对照

| 验收要求 | 交付物 | 验证方式 | run_tests 断言 |
|---|---|---|---|
| 正常路由 | `agent_router.py` 可配置路由表 | 任务精确命中规则 → 转发到目标 agent | 1、2、3 |
| 无匹配路径 | 无匹配 → 失败回退 | 未命中任何规则 → 明确 no_match（有/无兜底两种）| 4、5、6 |
| 转人工路径 | 转人工规则 → 人工接管单 | 高额支付任务 → 生成 HUMAN-XXX 单 | 7 |
| 人工接管入口 | `claim_human` / `pending_human` | 认领接管单、查待办 | 8、9 |
| 三类路径完整性 | 审计 + stats | 三路径都被走到且枚举精确 | 10、11 |
| 演示直观可核验 | `demo.py` | 三类路径直观演示（退出码 0）| — |
| 使用说明 | `README.md` + `SETUP.md` | 命令全部实测 | — |
| 验证记录 | `docs/验证记录.md` | 真实执行输出快照 | — |
